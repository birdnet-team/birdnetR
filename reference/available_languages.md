# Get Available Languages for BirdNET Model

Retrieve the available languages supported by a specific version of
BirdNET.

## Usage

``` r
available_languages(version)
```

## Arguments

- version:

  character. The version of BirdNET to use (default is "v2.4", no other
  versions are currently supported).

## Value

A sorted character vector containing the available language codes.

## Examples

``` r
if (FALSE) available_languages("v2.4") # \dontrun{}
```
