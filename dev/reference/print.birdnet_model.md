# Print a BirdNET model

Prints a one-line description of a loaded model: model, version,
backend, precision, language and number of classes.

## Usage

``` r
# S3 method for class 'birdnet_model'
print(x, ...)
```

## Arguments

- x:

  A BirdNET model object, see
  [`birdnet_load()`](https://birdnet-team.github.io/birdnetR/dev/reference/birdnet_load.md).

- ...:

  Ignored.

## Value

`x`, invisibly.
