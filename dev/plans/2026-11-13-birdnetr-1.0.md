# birdnetR 1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move birdnetR onto Python `birdnet` 1.4.x (BirdNET 3.0, Perch, geo, embeddings, custom classifiers, optional GPU) behind a renamed `birdnet_<verb>[_<what>]` API, ready for CRAN once upstream ships the final 3.0 model.

**Architecture:** birdnetR stays a thin reticulate wrapper. `.onLoad` declares the base `birdnet` install. Loaders declare the `[tf]`/`[pt]` extras via `py_require()` only when a backend needs them. Model objects carry their backend/library/precision so loads can announce themselves. Python output passes through unchanged.

**Tech Stack:** R (>= 4.1), reticulate (>= 1.46, uv-managed ephemeral env), testthat 3e with `local_mocked_bindings`, roxygen2 7.3.3, Python `birdnet` 1.4.x.

**Spec:** `dev/specs/2026-11-13-birdnetr-1.0-design.md` (read it before any task; section numbers below refer to it).

## Global Constraints

- Python requirement: `birdnet>=1.4,<2`, `python_version = ">=3.11,<3.14"`. The lower bound is raised only in Task 13.
- Imports stay `reticulate (>= 1.46)` only. No new R dependencies.
- Exported names follow `birdnet_<verb>[_<what>]` (spec §6.1 table is authoritative). No `predict()`/`encode()` S3 methods remain. `as.data.frame()` and `print()` stay S3.
- Upstream output column names pass through unchanged (spec §4).
- Arguments that default to `NULL` are omitted from the Python call (`compact_nulls()`).
- User-visible output only via `message()` (or inside `print()` methods). No `cat()` elsewhere. No color.
- R sources are ASCII-only: write `·` as `"\u00b7"`.
- Every example that needs Python is in `\dontrun{}`.
- Unit tests (`test-unit-*`) never start Python: mock `py_birdnet`, `py_birdnet_globals`, `py_builtins`, `get_df_helper()`, and `reticulate::` functions with `testthat::local_mocked_bindings()`. Integration tests (`test-integration-*`) stay gated by `is_full_test_env()`.
- After changing roxygen comments, run `Rscript -e 'devtools::document()'` and commit the regenerated `NAMESPACE`/`man/`.
- Unit test command: `Rscript -e 'devtools::test(filter = "^unit")'`. Single file: `Rscript -e 'devtools::test(filter = "unit-<name>")'`.

## Review Focus

1. **Fresh session, first call needs `[tf]`** (`birdnet_load_perch()` before anything else) and **the same after a 3.0 model was already loaded**: both must load and predict. Pinned by Task 1 checks A–B and Task 12 test `"Perch loads after a 3.0 model in the same session"`.
2. **A recording with no detections above `min_confidence`**: `as.data.frame()` returns a 0-row data frame with the five standard columns, and `birdnet_write()` writes a header-only CSV. Pinned in Task 6 (`"predictions_to_dict keeps column names for an empty result"`) and Task 12.
3. **Loading models in a loop or a knitted report**: the logo appears once per session, one line per load, and `suppressMessages()` silences both. Pinned in Task 4.
4. **A user who set `RETICULATE_PYTHON` to their own env**: birdnetR must not overwrite it. Pinned in Task 2.
5. **`birdnet_use_gpu()` called after a model was loaded**: a clear error saying to restart R and call it first. Pinned in Task 10.
